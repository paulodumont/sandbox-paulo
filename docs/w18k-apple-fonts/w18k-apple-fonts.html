W18K · Sistema interno

Fontes da Apple
aplicadas às telas da W18K

Comparativo visual das famílias tipográficas que a Apple usa no iOS e no macOS, aplicadas ao Dashboard, à tela de Produto, à tela de Cliente e ao cadastro de Cliente. Os dados nas telas são ilustrativos.

Decisão

SF Pro com números tabulares em todo o sistema: SF Pro Display Semibold nos títulos e valores grandes, SF Pro Text no corpo, com números tabulares ativados em KPIs, tabelas e formulários. SF Mono apenas em SKU, pedidos e certificados.

Regra vigente a partir de 7 de setembro de 2026 para toda tela nova e toda tela existente que for alterada. A Opção B (New York) fica só como referência para site e materiais de cliente.

Implementação

Como aplicar no sistema

No Mac, iPhone e iPad as fontes já estão no aparelho e o navegador usa a SF Pro e a New York nativas. No Windows e no Android elas não existem e a licença da Apple não permite embutir os arquivos no site, então o sistema cai para a fonte de reserva. A mais parecida com a SF Pro é a Inter (gratuita).

CSS · Opção A
:root {
  --font-text: -apple-system, "SF Pro Text",
               "Inter", system-ui, sans-serif;
  --font-display: -apple-system, "SF Pro Display",
               "Inter", system-ui, sans-serif;
  --font-mono: ui-monospace, "SF Mono",
               "JetBrains Mono", monospace;
}
body       { font-family: var(--font-text);
             font-variant-numeric: tabular-nums; }
h1, h2, .kpi-value, .price
           { font-family: var(--font-display);
             font-weight: 600; letter-spacing: -0.01em; }
.sku, .order-id, .certificate
           { font-family: var(--font-mono); }
CSS · Opção B (títulos)
:root {
  --font-title: ui-serif, "New York",
                "Source Serif 4", Georgia, serif;
}
h1, h2, .product-name, .customer-name
           { font-family: var(--font-title);
             font-weight: 600; }
